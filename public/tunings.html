Why they exist

The short version: Nadi and most synths speak slightly different pitch languages.

Most synths use twelve-tone equal temperament, or 12-TET, where every semitone has the same frequency ratio. It is a clever compromise: one keyboard can move freely between keys without being retuned.

Just intonation builds intervals from small whole-number ratios such as 3/2, 5/4 and 9/8. With stable, harmonically rich sounds, more partials coincide and beating can be reduced, giving intervals a more fused, settled quality.

These files are fixed just-intonation realisations of Nadi's raga- and rasa-derived pitch sets. They are not a claim that each raga has one universally correct set of frequencies: in Indian classical performance, intonation is shaped by melodic context, movement and ornament. Here, the aim is practical — to give Nadi and compatible instruments the same pitch framework.

The difference is small but audible. A 5/4 major third sits about 14 cents below its 12-TET equivalent; a 5/3 major sixth about 16 cents below. Layer a JI-tuned resonator with a 12-TET synth and sustained notes can beat against one another. That is a tuning mismatch, not a mix problem. Load the matching file and the layers settle together.

How to use them

Choose your tonic (Sa), load the tuning, then match Nadi.

Ableton Live 12

  • Open the folder for your tonic — 00_C, 05_F, and so on.
  • Add the downloaded folder to Live's Places and double-click the .ascl file, or drag the file directly into Live's Tuning section.
  • The piano roll now shows the tuning's swara names — Sa, Re, ga, Ma, Pa — instead of standard note names.
  • Live's own instruments follow automatically.

Live applies one tuning to the whole Set. Use Bypass Tuning on any MIDI track that should remain in 12-TET; Drum Racks bypass it automatically. Compatible MPE plug-ins can follow when their pitch-bend range is set to 48 semitones.

Scala-compatible synths

  • Load the matching .scl in the synth's own tuning or microtuning section.
  • Spire and Pigments import .scl directly; many other instruments do too.
  • Standard .scl files store intervals rather than an absolute root. Set the synth's tonic or reference note to the folder you chose, with A4 at 440 Hz.
  • Some instruments use a separate keyboard-mapping file (.kbm). If prompted, follow the synth's own microtuning instructions rather than assuming its default.

This route works in any DAW that can host the synth and doesn't depend on MPE.

With Nadi

  • Set Nadi's Rasa to the matching mode.
  • Shift-click Nadi's Sa dial to the same note as the folder you loaded — Shift snaps it to exact semitones.
  • Use the octave arrows to place it in whichever register suits the track.
  • Done. Resonators and instruments in one tuning.

For the closest alignment, match both Rasa and Sa. Once aligned, try moving Nadi by a fourth or fifth as a deliberate harmonic colour and judge the result by ear.

What's in the download

  • Fifteen tuning sets — the fourteen pitch sets used by Nadi: Shanta, Bhairavi, Yaman, Malkauns, Bhairav, Todi, Megh, Pahadi, Marwa, Darbari, Durga, Bhupali, Kafi and Charukesi, plus a twelve-degree chromatic set for free playing.
  • All twelve tonics — one folder per root, so there's no interval editing or arithmetic.
  • Two formats — .ascl for Ableton Live 12, with swara names in the piano roll and an embedded reference pitch; .scl in the original Scala format for compatible instruments.
  • A Sa frequency table — every root across five octaves, for setting a resonator or synth by frequency rather than by note.
  • Exact ratios — every interval written as a fraction with its value in cents, so you can see precisely what you're playing.

The .ascl files use A4 = 440 Hz as their embedded reference. Standard .scl files describe interval relationships rather than an absolute pitch, so set the tonic and reference frequency inside the synth.

A tuning is not the whole raga. These files set pitch positions; characteristic phrases, ascending and descending movement, note hierarchy and ornamentation remain part of the music.

Where they came from

These tunings began as companions to Nadi, a seven-voice resonator effect whose resonance banks use fixed just intervals drawn from raga and rasa modes. Nadi can sound beautiful on its own, but when its resonances sit against a 12-TET synth, the two pitch frameworks can pull slightly apart. These files let compatible instruments meet Nadi on the same framework.

They're useful beyond Nadi and free whether or not you ever use it. If you're curious what those resonances can do to a drum loop, there's a 30-day trial.
